# Thành phần bên thứ ba

Tất cả được đóng gói cùng MiniLab lúc build. Web không tải gì từ máy chủ bên ngoài.

| Thành phần | Dùng cho | Giấy phép |
|---|---|---|
| [three.js](https://threejs.org) | Dựng và hiển thị nhân vật 3D | MIT |
| [Phosphor Icons](https://phosphoricons.com) (`@phosphor-icons/core`) | Biểu tượng giao diện | MIT |
| [Nunito](https://github.com/googlefonts/nunito) (qua `@fontsource-variable/nunito`) | Phông chữ, có hỗ trợ tiếng Việt. File phông nằm trong `src/shared/fonts/` | SIL Open Font License 1.1, xem `src/shared/fonts/OFL.txt` |
| [Vite](https://vite.dev) | Công cụ build (không nằm trong web xuất bản) | MIT |
